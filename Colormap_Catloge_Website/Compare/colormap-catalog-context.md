# Colormap Catalog Website - Project Context

## Project Overview
The Colormap Catalog is a static frontend web application designed to showcase and compare around 180 high-resolution `.png` visualizations of a 3D point cloud (`boy_01_PC_v2`) rendered with different colormaps. The website serves as an interactive catalog with a sidebar navigation, dynamic scroll-spy, and a fullscreen pan/zoom image viewer.

## Technology Stack
- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Vanilla CSS (with CSS variables for theming)
- **Deployment**: Cloudflare Pages (via Wrangler CLI)

## Core Implementation Details

### 1. Data Management
- **`src/colormaps.json`**: An auto-generated array of all ~180 colormap names. The application uses this JSON file to dynamically render both the Sidebar navigation and the main content sections, keeping the code completely DRY.

### 2. Key Components
- **`App.jsx`**: The main layout orchestrator holding the Sidebar, MainContent, and the ImageViewerModal.
- **`Sidebar.jsx`**: Maps through the colormaps to create navigation links. On mobile (<=1024px), it transforms into an off-canvas "hamburger" drawer menu with a sticky header.
- **`ColormapSection.jsx`**: A reusable component for each colormap. It uses `forwardRef` to connect to the intersection observer. The image `src` uses a relative path `boy_01_PC_v2/[name].png` which resolves correctly due to Vite's `publicDir: 'Public'` configuration.
- **`ImageViewerModal.jsx`**: An isolated, fullscreen modal for inspecting images. It includes:
  - Scroll wheel zoom functionality.
  - Mouse click-and-drag panning.
  - Native mobile touch events (`onTouchStart`, `onTouchMove`, `onTouchEnd`) for fluid panning on mobile devices, preventing default screen scroll during the interaction.

### 3. Custom Hooks
- **`useScrollSpy.js`**: Utilizes the native browser `IntersectionObserver` API. It watches all image sections and dynamically updates the `activeSection` state. This state highlights the currently viewed colormap in the Sidebar navigation.

### 4. Styling & Responsiveness (`index.css`)
- **Desktop**: A split-pane layout with a fixed 260px left sidebar and a scrollable main content area.
- **Mobile**: A single-column layout triggered at `max-width: 1024px`. The font sizes for headers and section titles are dynamically reduced (`0.95rem` and `0.75rem`) to fit small screens. The vertical padding and margins are also aggressively tightened to reduce dead space.

## Build and Deployment Strategy
Due to the sheer size of the 180 image assets (totaling gigabytes), the traditional `git push` deployment strategy is non-viable (GitHub blocks repos this large). 

Instead, the project relies on a direct-to-CDN deployment model:
1. **Build**: Run `npm run build` to package the React code into the `dist/` folder.
2. **Deploy**: Run `npx wrangler pages deploy dist` directly from the terminal.
3. **Hosting**: Hosted completely for free on **Cloudflare Pages**, which offers unmetered bandwidth perfectly suited for serving this massive image catalog globally. Wrangler efficiently only uploads the code that changes, keeping subsequent deployments lightning-fast.
